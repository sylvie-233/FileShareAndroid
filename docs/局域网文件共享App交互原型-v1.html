Interactive Prototype

FileShare · 局域网文件共享

原型 v1.0 · Android App

点击启动 / 关闭服务后，局域网内设备通过浏览器访问该地址即可上传、下载文件。数据只保存在本机。

  • 一键启动 / 关闭 HTTP 共享服务
  • 局域网地址 + 二维码，手机扫码直连
  • 浏览器端拖拽上传（本页为 App 端视角）
  • 文件搜索、分页、下载、分享、删除
  • 连接设备实时可见，端口 / 限额可配置
💡 原型内所有数据均为模拟数据，交互仅用于演示流程。
