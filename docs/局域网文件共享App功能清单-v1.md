## 1. 服务控制（核心）

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 1.1 | 一键启动/关闭服务 | 大号电源按钮，启动中有过渡动画，运行中有呼吸灯指示 | ✅ 原型 |
| 1.2 | 服务状态展示 | 顶部状态徽章（未运行/运行中）+ 服务页实时状态文案 | ✅ 原型 |
| 1.3 | 关闭服务二次确认 | 关闭前弹窗提示"已连接设备将无法访问" | ✅ 原型 |
| 1.4 | 运行指标 | 运行时长、实时速率、累计传输量 | ✅ 原型（模拟） |
| 1.5 | 前台服务常驻通知 | Android 前台服务，显示"服务运行中"常驻通知，点击可回到 App | ⬜ |
| 1.6 | 开机自动启动服务 | `BOOT_COMPLETED` + 前台服务；国产 ROM 需自启动引导页 | ✅ 原型（开关） ⬜ 实现 |
| 1.7 | 共享时保持屏幕常亮 | 避免传输中息屏导致服务中断 | ✅ 原型（开关） ⬜ 实现 |
| 1.8 | 电池优化白名单引导 | 检测并引导用户加入电池优化白名单，防止后台被杀 | ⬜ |

## 2. 局域网访问（核心）

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 2.1 | 局域网地址识别 | 自动获取本机局域网 IP，拼接 `http://ip:port` | ✅ 原型（模拟） ⬜ 实现 |
| 2.2 | 地址一键复制 | 复制完整访问 URL 到剪贴板 | ✅ 原型 |
| 2.3 | 二维码分享 | 展示访问地址二维码，其他设备扫码直连 | ✅ 原型 |
| 2.4 | 已连接设备列表 | 实时显示在线设备（IP + UA 解析的设备类型 + 最后活跃时间） | ✅ 原型（模拟） ⬜ 实现 |
| 2.5 | 设备在线检测 | 请求活动表 + WebSocket/心跳保活（详见功能设计文档） | ⬜ |
| 2.6 | 访问端 Web 页面 | 其他设备浏览器打开 URL 后的上传/下载页面（可复用 FileShareTs 静态页） | ⬜ |

## 3. 文件管理（核心）

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 3.1 | 文件上传（浏览器端） | 其他设备通过浏览器上传，支持多选与拖拽，流式写盘 | ✅ 原型（模拟） ⬜ 实现 |
| 3.2 | 上传进度展示 | App 端显示上传中任务的文件名与进度条 | ✅ 原型 |
| 3.3 | 文件下载 | 浏览器端点击下载；中文名按 UTF-8 正确处理 | ✅ 原型 |
| 3.4 | 下载链接复制 | App 端可复制单个文件的直链 | ✅ 原型 |
| 3.5 | 文件列表 | 显示文件名、类型徽章、大小、修改时间、来源设备 | ✅ 原型 |
| 3.6 | 文件搜索 | 按文件名实时搜索（防抖 150ms） | ✅ 原型 |
| 3.7 | 分页浏览 | 每页 8 个，上/下翻页 | ✅ 原型 |
| 3.8 | 删除单个文件 | 删除前二次确认，提示不可恢复 | ✅ 原型 |
| 3.9 | 清空全部文件 | 二次确认后批量删除 | ✅ 原型 |
| 3.10 | 空状态与无结果状态 | 无文件、搜索无结果的占位提示 | ✅ 原型 |
